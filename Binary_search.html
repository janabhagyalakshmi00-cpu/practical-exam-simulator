Binary Search

Binary Search finds an element in a sorted array by repeatedly dividing the search range into two halves.

Concept

Binary Search is a searching technique used to find an element in a sorted array. It checks the middle element and compares it with the target. Based on the comparison, it eliminates half of the search area and continues searching until the element is found or the search area becomes empty.

Example

Array: [10, 20, 30, 40, 50]
Search element: 40
Middle element is 30.
40 is greater than 30, so search the right half.
Next middle element is 40.
40 is found

Important

Binary Search works efficiently because the array is sorted.

Procedure

  1. Start with a sorted array.
  2. Take the element that needs to be searched.
  3. Find the middle element of the current search range.
  4. Compare the middle element with the target element.
  5. If they are equal, the target element is found.
  6. If the target is greater, Search the right half.
  7. If the target is smaller, Search the left half.
  8. Repeat the process until the element is found or the search range becomes empty.
