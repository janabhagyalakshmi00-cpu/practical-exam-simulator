Selection Sort

Selection Sort repeatedly finds the smallest element from the unsorted part of an array and places it at the beginning of that part.

Concept

Selection Sort is a simple sorting technique that divides the array into sorted and unsorted parts. It repeatedly finds the smallest element from the unsorted part and swaps it with the first element of the unsorted part. This process continues until the entire array is sorted.

Example:

Array: [5, 3, 8, 4, 2]
Find the smallest element → 2
Swap 2 with 5 → [2, 3, 8, 4, 5]
Find the smallest element from the remaining part → 3
3 is already in the correct position.
Continue the same process until the array is sorted.

Important

Selection Sort selects the smallest element from the unsorted part and places it at the beginning of the unsorted part.

Time Complexity

Best case: O(n²)

Average case: O(n²)

Worst case: O(n²)

Procedure

  1. Start with the first element of the array.
  2. Assume the first element is the smallest element.
  3. Compare it with the remaining elements in the unsorted part.
  4. Find the smallest element in the unsorted part.
  5. Swap the smallest element with the first element of the unsorted part.
  6. Move to the next position and repeat the same process.
  7. Continue until the entire array is sorted.

Implementation

Problem

Write a Java program to sort an array using the Selection Sort technique. The program should repeatedly find the smallest element from the unsorted part and place it in its correct position. 

    
        import java.util.*;

        public class Selection_Sort{
            public static void main(String[]args){

                Scanner sc=new Scanner(System.in);

                System.out.println("enter no.of elements:");
                int n=sc.nextInt();

                int[] arr=new int[n];

                System.out.println("Enter your elements:");
                for(int i=0;i<arr.length;i++){
                    arr[i]=sc.nextInt();
                }

                for(int i=0;i<arr.length-1;i++){

                    int min=i;

                    for(int j=i+1;j<arr.length;j++){

                        if(arr[j]<arr[min]){
                            min=j;
                        }
                    }

                    int temp=arr[i];
                    arr[i]=arr[min];
                    arr[min]=temp;
                }

                System.out.println("Sorted array:");

                for(int i=0;i<arr.length;i++){
                    System.out.print(arr[i]+" ");
                }
            }
        }
