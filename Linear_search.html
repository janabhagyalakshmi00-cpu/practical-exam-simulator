Linear Search

Linear Search checks each element in an array one by one until the required element is found or the array ends.

Concept

Linear Search is a simple searching technique used to find a specific element in an array. It checks each element one by one from the beginning until the required element is found or the end of the array is reached. If the element is found, its position is returned. If it is not found, we indicate that the element does not exist in the array.

Example:

Array: [10, 20, 30, 40, 50] Search element: 30 Linear Search checks 10, then 20, and then 30. Since 30 is found, the search stops.

Procedure

  1. Start with the given array of elements.
  2. Take the element that needs to be searched.
  3. Compare the search element with each array element from the beginning.
  4. If a match is found, record its position and stop searching.
  5. If the end of the array is reached without finding a match, report that the element is not present.

Viva

Question 1

What is Linear Search?

A searching technique that checks elements one by one until the target is found or the array ends.

Question 2

Can Linear Search work on an unsorted array?<

Yes. Linear Search can work on both sorted and unsorted arrays.

Question 3

What is the time complexity of Linear Search?

Best case: O(1), Worst case: O(n).

Question 4

What happens if the target element is not present in the array?

The entire array is checked and we report that the element was not found.

Question 5

What is the difference between index and position?<

Index starts from 0, while position usually starts from 1.
