Binary Search concept:

* Searches for an element in a sorted array.
* Checks the middle element.
* Compares the middle element with the target.
* Eliminates half of the search range.
* Repeats until the target is found or the search range becomes empty.
* The array must be sorted.

Example used:
Array: [10, 20, 30, 40, 50]
Target: 40

Binary Search:
30 → search right half → 40 → found

## BINARY SEARCH PROCEDURE

1. Start with a sorted array.
2. Take the element that needs to be searched.
3. Find the middle element of the current search range.
4. Compare the middle element with the target element.
5. If they are equal, the target element is found.
6. If the target is greater, search the right half.
7. If the target is smaller, search the left half.
8. Repeat until the element is found or the search range becomes empty.

## BINARY SEARCH IMPLEMENTATION

Java program uses:

low
high
mid
target
flag
while loop
break

Important logic:

low = 0
high = arr.length - 1

mid = low + (high - low) / 2

If:
arr[mid] == target
→ target found
→ flag = true
→ break

If:
arr[mid] > target
→ high = mid - 1

Otherwise:
→ low = mid + 1

After the loop:

if(!flag)
→ Element not found.
