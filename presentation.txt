SLIDE 2 — PROBLEM STATEMENT

UPI has become an important part of digital payments.

As digital payments continue to grow, detecting fraudulent transactions quickly has become an important challenge.

A fraudulent transaction can sometimes look very similar to a normal transaction, which makes it difficult to identify.

The system needs to analyze different transaction details and identify unusual patterns.

Another important requirement is speed.

Since UPI transactions happen in real time, fraud detection also needs to happen within a very short time.

There is also another challenge: fraud transactions are much fewer than genuine transactions.

So, the model needs to identify rare suspicious transactions without incorrectly blocking too many genuine users.

Therefore, our main problem is:

How can we detect suspicious UPI transactions quickly and accurately using AI, Machine Learning, and Quantum Computing?

SLIDE 3 — PROPOSED SOLUTION

To address this problem, we propose a real-time UPI fraud detection system.

Our solution follows a hybrid approach using classical machine learning and quantum-inspired techniques.

First, the system receives the transaction data.

The transaction contains different information and features that can help us identify whether its behavior is normal or unusual.

Next, we use feature bundling.

Feature bundling combines important transaction attributes into a more compact representation.

This reduces the complexity of the data and makes it easier for the detection model to process.

After that, the compact transaction representation is passed to our quantum-inspired anomaly model.

The model looks for patterns that are different from normal transaction behavior and produces a fraud-risk score.

Example

Let us take a simple example.

Suppose a user normally makes UPI transactions between ₹500 and ₹2,000.

Suddenly, a transaction of ₹50,000 is made to a new and unusual destination.

Instead of looking only at the transaction amount, our proposed system can consider multiple transaction features together.

First, the transaction enters our real-time pipeline.

Then, feature bundling combines the important features into a compact representation.

Next, the quantum-inspired anomaly model checks whether the transaction looks significantly different from normal transaction patterns.

If the transaction receives a high fraud-risk score, it can be flagged for further verification.

So, the system helps identify suspicious behavior instead of simply treating every transaction in the same way.

Quantum component

Now, where does quantum computing come into our solution?

Our current approach uses quantum-inspired methods that can run on classical hardware, so real-time fraud scoring does not have to wait for advanced quantum hardware.

At the same time, we plan to use Qiskit and quantum simulators to test quantum machine-learning approaches such as quantum kernels and QSVM.

These approaches can later be compared with classical machine-learning models and our quantum-inspired baseline.

So, our approach is hybrid:

Real-time scoring uses classical and quantum-inspired methods for speed, while quantum models are explored separately for future validation.

Overall, our solution aims to combine fast processing, compact transaction features, anomaly detection, and quantum-inspired techniques to address the challenges of real-time UPI fraud detection.
